Engineering Portfolio
Website

A responsive, multi-page portfolio designed to present mechatronics work clearly across CAD, robotics and programming. Its reusable structure makes future projects easy to add without rebuilding the layout.

Role UI / UX · Front-end development
Project type Personal portfolio
Tools HTML · CSS · JavaScript

The challenge

Engineering projects combine mechanical design, electronics and software, but those disciplines can be difficult to present in one consistent format. The site needed to remain visually distinctive and easy to scan while also being simple to maintain without a framework or build process.

Engineering approach

The website uses semantic HTML for its content, shared CSS for the visual system and a small JavaScript file for behaviour. Project categories use coordinated accent colours, while each case study follows the same reusable information structure.

  • CSS custom properties keep the dark and light themes consistent from one colour system.
  • A reusable project template separates editable content from the shared layout and interactions.
  • Responsive grids keep project cards and technical content readable on desktop and mobile screens.
  • Motion effects respect the browser's reduced-motion preference for accessibility.

Outcome & next steps

The result is a lightweight portfolio that runs directly in a browser, preserves theme preference locally and can grow one project page at a time. Future iterations can add completed project media, test results and deployment automation without changing the core content structure.

STRUCTURE

Reusable cards and case-study pages.

THEME
